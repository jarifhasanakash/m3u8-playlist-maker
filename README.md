# 🎬 M3U8 Playlist Maker

A fast, responsive, and modern web application to generate, edit, and organize .m3u / .m3u8 playlists for media players like **VLC**, **Kodi**, **IINA**, **PotPlayer**, and mobile IPTV apps.

## 🚀 Live Demo
👉 **[https://jarifhasanakash.github.io/m3u8-playlist-maker/](https://jarifhasanakash.github.io/m3u8-playlist-maker/)**

---

## ✨ Features
- 📱 **Fully Responsive & Mobile-Optimized**: Designed for smartphones, tablets, foldables, and desktops with native touch drag-and-drop support, dynamic viewport handling, and notch/safe-area support.
- 🚫 **Smart Duplicate Detection**: Automatically prevents duplicate links from being added to your playlist, alerts you with custom toast notifications, and visually highlights existing tracks.
- ✂️ **Automatic Link Spacing & Paste Separation**: Paste multiple space/comma-separated links at once, and they are automatically formatted with clean paragraph line breaks.
- 🔄 **Reordering**: Drag-and-drop tracks on desktop or touchscreens, or use the quick Move Up / Move Down buttons.
- ✏️ **Inline Title Editing**: Rename any video, movie, or series episode before exporting.
- 📂 **Import Existing Playlists**: Open existing .m3u or .m3u8 playlists to inspect, edit, and re-export.
- 🏷️ **Intelligent Parsing**: Automatically detects TV series season & episode codes (S01E01, 1x01), movie release years, and cleans up release garbage tags.
- 🎨 **VLC-Inspired Modern Dark UI**: Polished glassmorphism interface with non-blocking toast notifications and confirmation dialogs.

## 🛠️ Usage
1. Paste or drop your video stream links into the input field.
2. Click **Add Links to Playlist** (or press Ctrl + Enter).
3. Reorder tracks or edit titles as needed.
4. Enter your desired **Playlist Name**.
5. Click **Download M3U8 Playlist** to export your .m3u8 file.
